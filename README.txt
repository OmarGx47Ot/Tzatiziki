OUZO & OLIVE WEBSITE

Files:
- index.html: page structure and content
- styles.css: project styles and palette variables
- script.js: Tailwind theme configuration and interactive behavior

To run: keep all three files in the same folder and open index.html in a modern browser. An internet connection is required for the Tailwind CDN, Google Fonts, Font Awesome, the remote hero image, and the embedded YouTube video.

Palette:
- Phthalo Green: #0D3B2E
- Creamy White: #FAF7F2
- Soft Green Border: #D5E3DC
- Phthalo Dark (darker shade for hover/footer): #082A20
